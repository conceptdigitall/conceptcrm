# Registros de Decisão de Arquitetura (ADR)

Este diretório armazena decisões arquiteturais do CRM Concept em formato conciso de 5 linhas:

- **Data:** AAAA-MM-DD
- **Contexto:** Qual problema ou restrição motivou a decisão.
- **Decisão:** O que foi escolhido e implementado.
- **Alternativas:** Opções consideradas e rejeitadas.
- **Consequência:** Trade-offs, impactos positivos e restrições geradas.
